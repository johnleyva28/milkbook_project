# Paleta 08 — Cielo Lechero (Azul Tradicional)

> **Identidad**: La convención global más fuerte: **azul = leche, pureza, frescura, confianza**. Es la paleta que cualquier persona en el mundo asocia con productos lácteos. Perfecta para una primera versión "sin sorpresas".

## Inspiración
- Convenciones globales de branding lácteo: "Blues and whites: purity, hygiene, and freshness" (Confetti Design).
- Dairyproducts milk web UI colors: `#0AACEE, #78D1F0, #7CB11B, #6372AE, #CAC4A2, #343C44`.
- Nestlé, Danone, Müller, Yili: azul como color dominante.

## Contraste WCAG
- Azul Profundo `#102A43` sobre Blanco Nube `#F8FBFF`: **15.9:1** (AAA) ✓
- Azul Cielo `#0277BD` sobre Blanco Nube: **7.5:1** (AAA) ✓
- Verde Pradera `#7CB342` sobre Blanco Nube: **2.9:1** (Fail — usar solo como botón grande, no texto)
- Rojo Fresa `#D32F2F` sobre Blanco Nube: **5.8:1** (AA) ✓

## Mapeo a funciones
| Función | Color |
|---------|-------|
| Login / Splash | Azul Cielo Profundo `#0277BD` |
| Botón confirmar | Verde Pradera `#7CB342` (solo botón grande con texto blanco) |
| Adelantos | Amarillo Sol `#FFB300` |
| Discrepancia | Rojo Fresa `#D32F2F` |
| Pantalla "Hoy vendí" | Azul Lechero (banner con texto blanco) |

## ¿Cuándo usarla?
✅ Si quieres **transmitir confianza rápida** sin tomar riesgos.
✅ Perfecta para el **MVP** si necesitas validar rápido.
✅ Ideal para web admin con stakeholders bancarios/SUNAT.
⚠️ Es la opción más "genérica" — muchos competidores se ven igual. Diferénciate con la UX, no solo el color.
