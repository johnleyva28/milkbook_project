# Paleta 20 — Indigo Mountain (Premium B2B + Rural)

> **Identidad**: La paleta más **premium y corporativa**. Indigo profundo + dorado + gris. Pensada para Milkbook como una **plataforma financiera rural seria** que conecta con bancos, SUNAT y proveedores industriales.

## Inspiración
- Branding fintech premium (Stripe, Square, Wise).
- Banco de Crédito del Perú (BCP) paleta corporativa.
- "Terra roxa" (roxa = púrpura en portugués) — sensación premium tropical.
- Logo de AgriTrust Protocol: indigo + dorado = confianza + valor.

## Contraste WCAG
- Carbón Indigo `#1F1F2E` sobre Blanco Perla `#FAFAFA`: **16.7:1** (AAA) ✓
- Indigo Profundo `#1A1F71` sobre Blanco Perla: **14.3:1** (AAA) ✓
- Dorado Solar `#C9A227` sobre Carbón Indigo: **6.9:1** (AAA) ✓
- Carmesí `#A52A2A` sobre Blanco Perla: **7.8:1** (AAA) ✓

## ¿Cuándo usarla?
✅ Si Milkbook quiere posicionarse como **"el BCP del campo"** — plataforma financiera seria.
✅ Para web admin con stakeholders corporativos.
✅ Para reportes exportables a PDF para el banco / SUNAT.
⚠️ Puede parecer "fría" o "lejana" para el usuario rural. Úsala con calidez en copywriting.
