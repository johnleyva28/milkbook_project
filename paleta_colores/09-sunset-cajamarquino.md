# Paleta 09 — Sunset Cajamarquino (Atardecer Andino)

> **Identidad**: Los colores del atardecer en las alturas de Cajamarca (3,500 msnm). Naranjas, rosas, púrpuras y dorados cálidos. **Romántica, optimista, moderna**.

## Inspiración
- Sky de Cajamarca al atardecer (Cumbe Mayo, Llacanora).
- Paletas "Sunset" de Dribbble.
- Branding de start-ups modernos (Stripe, Linear) que usan degradados cálidos.

## Contraste WCAG
- Carbón Tinta `#1D1D1D` sobre Crema Rosada `#FFF1E6`: **16.4:1** (AAA) ✓
- Naranja Atardecer `#E85D04` sobre Crema Rosada: **4.8:1** (AA) ✓
- Carmesí Profundo `#9D0208` sobre Crema Rosada: **8.3:1** (AAA) ✓
- Púrpura Andino `#5A189A` sobre Crema Rosada: **9.2:1** (AAA) ✓

## Mapeo a funciones
| Función | Color |
|---------|-------|
| Botón confirmar | Amarillo Inti `#FFB703` |
| Adelantos | Naranja Atardecer `#E85D04` |
| Pantalla "Hoy" | Naranja → Salmón (degradado CTA) |
| Discrepancia | Carmesí Profundo `#9D0208` |
| Logros / hitos | Rosa Cielo `#FF6B9D` |

## ¿Cuándo usarla?
✅ Si Milkbook quiere ser **moderno, vibrante, joven** — para atraer al productor de 25-35 años.
✅ Perfecta para campañas de marketing y notificaciones push.
✅ Para onboarding gamificado.
⚠️ Puede sentirse "juvenil" para el lechero de 50+ años. Valida con usuarios.
