## Cómo crear un sprint nuevo

1. Copiar `plantilla-sprint.md` a `sprint-NN/`.
2. Crear las carpetas `planning.md`, `tablero.md`, `review-retro.md` dentro de `sprint-NN/`.
3. Llenar el planning al inicio del sprint.
4. Actualizar el tablero cada vez que algo cambia (idealmente diario, o al menos 2 veces por semana).
5. Cerrar con review + retro al final.
6. Mover historias no terminadas al `product-backlog.md` para el próximo sprint.

## Convención de fechas

- Los sprints arrancan **lunes** y cierran **viernes**, 2 semanas después.
- Excepción: si el lunes es feriado, arrancar el martes y ajustar la duración.
- Las fechas objetivo por historia están **dentro del rango del sprint** (entre la fecha de inicio y la fecha de cierre).
