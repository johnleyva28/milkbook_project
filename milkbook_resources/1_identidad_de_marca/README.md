## 🥛 El nombre MilkBook

**MilkBook = Milk + Book = "Cuaderno de leche"**

El nombre une dos raíces anglosajonas:
- **Milk** = el producto (leche).
- **Book** = el registro contable (cuaderno donde se asientan transacciones).

Se escribe **MilkBook** con M+B mayúscula para preservar la legibilidad etimológica, igual que **YouTube**, **FaceBook**, **AirBnB** o **PayPal**. En URLs y handles se usa `milkbook` (todo minúscula). En banners físicos puede ir en MAYÚSCULAS.

Ver: [`identidad_verbal/01-nombre-de-marca/`](./identidad_verbal/01-nombre-de-marca/) · [`comparativa-nombre.html`](./identidad_verbal/01-nombre-de-marca/comparativa-nombre.html)
