🖼️ Milkbook — Comparativa de Iconografía

6 librerías candidatas con los mismos iconos del contexto de Milkbook (litros, confirmar, cliente, alerta, sync, etc.) renderizados uno al lado del otro. Todo gratis, todo multiplataforma, todo alineado a la paleta cálida cremosa ya definida.

1. Las 6 candidatas en una tabla

⭐ RECOMENDADA
Phosphor Icons
5400+ iconos · 6 pesos (Thin/Light/Regular/Bold/Fill/Duotone) · MIT · ✅ Gratis · React + Flutter + Swift + Figma

Estilo rounded, friendly, coherente con la paleta cálida. Bold es perfecto para legibilidad al sol. Duotone permite iconos especiales con los pasteles del logo.

Lucide
1500+ iconos · Outline 2px · ISC · ✅ Gratis · React + Flutter + Swift

Friendly, ligeramente redondeado, un poco "moderno-saas". Misma familia que Feather. La más adoptada del momento.

Tabler Icons
6100+ iconos · Outline 2px · MIT · ✅ Gratis · React + Flutter + Swift

Más técnico y detallado. La mayor cobertura: 6000+ iconos. Bueno si necesitas dominios muy específicos.

Material Symbols
3000+ iconos · Variable font (4 ejes: wght/fill/grade/opsz) · Apache 2.0 · ✅ Gratis · Web + Flutter + Android

Es el sistema de Google. Coherente con Android. 4 ejes variables = control fino pero más complejo de implementar.

Heroicons
296 iconos · Outline + Solid · MIT · ✅ Gratis · React

Del equipo de Tailwind. Minimalista, técnico. Catálogo pequeño pero de altísima calidad.

Iconoir
1500+ iconos · Outline · MIT · ✅ Gratis · React + Flutter + Vue

Estilo elegante y uniforme. Buena alternativa si quieres algo intermedio entre Phosphor y Tabler.

5. Por qué recomiendo Phosphor para Milkbook

Coincidencias con lo que ya definimos

  • Personalidad moderna y juvenil + cercana y cálida → el estilo rounded de Phosphor encaja perfectamente. No es tan técnico como Tabler ni tan "saas-genérico" como Lucide.
  • Paleta cálida cremosa → el peso Bold (2px stroke) tiene buena presencia visual sobre fondo crema y al sol. El Fill se ve fuerte para acciones primarias.
  • Baja alfabetización → estudios muestran que iconos concretos funcionan mejor (Medhi, 2007). Phosphor tiene una buena selección de iconos que representan el objeto (jarra, gota, persona) en vez de abstracciones.
  • 6 pesos = control fino:
    • Bold → botones primarios, alertas (alta visibilidad)
    • Regular → UI estándar, tabs, navegación
    • Fill → estado activo, "toggle on"
    • Duotone → iconos especiales con verde+azul del logo (splash, empty states)
  • Multiplataforma completo: React, Flutter, Swift, web components, Figma. No hay que remapear cuando implementemos.
  • MIT gratis, sin atribución obligatoria, redistribución libre.

El dato técnico que importa

Phosphor pesa ~36 KB por peso en variable font. Cargar 3 pesos (Regular, Bold, Fill) son ~110 KB. Comparable con Inter (también ~110 KB). No impacta significativamente el bundle de la app.
