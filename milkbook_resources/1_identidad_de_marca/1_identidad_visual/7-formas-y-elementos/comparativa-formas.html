📐 Milkbook — Formas y Elementos Gráficos

Las formas y elementos son los "building blocks" de la marca: border radius (esquinas), strokes (líneas), sombras y formas decorativas. Esta guía define 4 decisiones que afectan el aspecto de TODOS los componentes de Milkbook.

1. Las 4 decisiones clave

Cada decisión está comparada con las opciones del mercado. La recomendada está marcada con ⭐.

📐 1. Border radius (esquinas)

Define la "personalidad geométrica" de la marca: técnica, amigable o cálida.

Opción A: Sharp (0-2px)

Cuadrado
0px
técnica, fría, precisa

2px
técnica con suavidad

Marcas: Apple, Linear, Notion (UI). Sensación seria, corporativa, precisa. Se siente "tech".

Opción B: Medium rounded (8-12px) ⭐ RECOMENDADA

8px
amigable, profesional
Card / modal
12px
cálido, moderno

Marcas: Stripe, Tailwind, Headspace, Linear (cards). Balance entre profesional y cálido. Encaja perfectamente con la paleta cremosa de Milkbook.

Opción C: Pill / full (999px)

999px
suave, infantil

Marcas: iOS, Material 3, Notion (cards). Demasiado infantil para Milkbook. Pierde seriedad técnica.

✏️ 2. Strokes (líneas)

El grosor de las líneas en bordes, divisores, iconos outline.

Stroke 1px
Sutil, divisores, table borders
Stroke 2px ⭐
Default, inputs, iconos
Stroke 2.5px
Inputs focused, hero
Stroke 3px
Acentos, ilustraciones
Regla de Milkbook: usar 2px como default, 1px para divisores muy sutiles, 2.5-3px para acentos. Color siempre cream-300 o cream-400 (nunca negro puro, coherente con la paleta cálida).

🌑 3. Sombras y elevación

Las sombras dan profundidad. Milkbook se ve al sol, así que las sombras deben ser muy sutiles o nulas.

Elevation 0 (sin sombra)
Default plano, mejor en app móvil
Elevation 1 ⭐
Sutil con tinte verde Milkbook
Elevation 2 ⭐
Modales, dropdowns web admin
Blur translúcido ⭐
Glass / frosted · overlays, modales web
Borde sutil (alternativa)
Mejor al sol, sin sombra
Regla de Milkbook: en la app móvil usar elevation 1 con tinte verde (rgba(42,120,42,0.06)) o un borde sutil de 1px (cream-300) — nada de sombras fuertes al sol. En el web admin se permite elevation 2 para modales y el efecto blur translúcido (frosted glass) con backdrop-filter: blur(...) para overlays, dropdowns y cards sobre patrones/texturas.

3. Sistema de tokens (resumen)

Border radius

/* CSS custom properties */
:root {
  --radius-sm:  6px;   /* small chips, tags */
  --radius-md:  8px;   /* buttons, inputs, icon buttons */
  --radius-lg:  12px;  /* cards, modals, list items */
  --radius-full: 9999px; /* avatars, pills, special toggles */
}

Strokes

:root {
  --stroke-thin:  1px;
  --stroke-base:  2px;  /* default */
  --stroke-bold:  2.5px;
  --stroke-accent: 3px;

  --color-border-subtle:  var(--cream-300);  /* #EBE3CC */
  --color-border-default: var(--cream-400);  /* #D9CCA8 */
  --color-border-strong:  var(--text);        /* #1A1F1A */
}

Sombras

:root {
  --shadow-none: none;
  --shadow-sm:  0 1px 2px rgba(42, 120, 42, 0.05);           /* muy sutil */
  --shadow-md:  0 2px 4px rgba(42, 120, 42, 0.06), 0 4px 12px rgba(42, 120, 42, 0.04); /* default web */
  --shadow-lg:  0 4px 12px rgba(42, 120, 42, 0.10), 0 8px 24px rgba(42, 120, 42, 0.06); /* modales */
  --border-sun: 1px solid var(--cream-300);  /* alternativa al sol, sin sombra */
}

/* Blur translúcido (frosted glass) — para overlays sobre patrones */
.glass {
  background: rgba(255, 255, 255, 0.45);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.6);
}

4. Reglas duras

Reglas de Milkbook para formas y elementos:
  • ✅ Border radius consistente: usar siempre tokens (--radius-sm/md/lg), nunca valores ad-hoc
  • ✅ Stroke 2px default, 1px para divisores muy sutiles, 2.5-3px para acentos
  • ✅ Sombras con tinte verde (rgba(42, 120, 42, ...)) para coherencia con la paleta, no sombras negras genéricas
  • ✅ En la app móvil: borde sutil en vez de sombra — mejor visibilidad al sol
  • ✅ Blur translúcido (frosted glass) con backdrop-filter: blur(...) — para overlays del web admin sobre patrones o fotos
  • ✅ Formas decorativas opacas 60-80% — no compiten con el texto
  • ❌ NO mezclar 3+ estilos de border radius en el mismo componente (ej: 8px en card pero 4px en inputs adentro)
  • ❌ NO sombras fuertes en la app móvil
  • ❌ NO bordes negros puros — siempre cream-300 o cream-400 para mantener calidez
