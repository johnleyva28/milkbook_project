🧱 Milkbook — Sistema de Composición

Cómo se organizan los elementos visuales en las pantallas: grid base 8pt, spacing scale, anatomía de pantalla, jerarquía visual, patrones por tipo de pantalla y reglas adaptativas. Cierra el bloque de identidad visual.

1. Grid base: 8pt con sub-grid 4pt ⭐

Decisión Milkbook: 8pt grid con sub-grid 4pt para detalles finos. Universal en Material Design 3, iOS HIG, Atlassian, IBM Carbon, Tailwind. Es la convención adoptada por toda la industria desde 2014.

8pt grid ⭐ RECOMENDADO

8dp / 8px / 8sp

"Estándar universal · limpio en todas las densidades"

2. Spacing scale (8pt) — 6 valores canónicos

Decisión Milkbook: 6 valores (4, 8, 16, 24, 32, 48) + 2 extendidos (64, 80). Suficiente variedad sin abrumar. Usar siempre tokens, nunca valores ad-hoc.

--space-1 4dp Icon-to-text gap dentro de chip · inset fino
--space-2 8dp Gap label-value · padding interno de chips
--space-3 12dp Input vertical padding · gap entre cards
--space-4 ⭐ 16dp DEFAULT · card padding · screen margin mobile
--space-5 24dp Card destacada · section gap · botón horizontal
--space-6 32dp Section divider · web margin · sticky CTA padding
--space-7 48dp Major section break · header-content separator
--space-8 64dp Solo hero marketing / onboarding

3. Touch targets: 56dp mínimo (no 48dp) ⭐

Decisión Milkbook: 56dp default (más generoso que el estándar Material de 48dp) · 60dp para acciones primarias. La baja alfabetización digital + uso con una sola mano + sol directo justifican ir más allá del estándar.

Reglas de listas:
✅ Máximo 6-8 cards visibles sin scroll (tap target 56dp + 12dp gap = 68dp × 8 = 544dp, justo en viewport ~640dp útil)

❌ NO listas planas con sub-headers (jerarquía confunde con baja alfabetización)

9. Modales vs Full screens vs Sheets

Full screen (con back)

Flujo crítico con >2 pasos (sacar cuentas, registrar visita).

Ocupa toda la pantalla + back arrow

Bottom sheet

Acción rápida (filtros, selección de fecha, opciones).

Slide desde abajo + dismiss

Modal centrado

Confirmación destructiva o alertas críticas.

Scrim oscuro + back dismiss

Toast / snackbar

Feedback efímero ("Guardado ✓").

Bottom, 4s, sin acción

Reglas duras:
❌ NO modal para flujos multi-paso (rompe el back)
❌ NO más de 1 modal anidado (modal en modal = error de UX)

10. Adaptación: light, dark, online, offline

Decisión Milkbook: el spacing/tamaños NO cambian entre light y dark. El layout NO se reorganiza entre online y offline. Solo cambian colores y banners de estado.

Light ↔ Dark

Solo cambian colores (paleta tokens). Grid, spacing, jerarquía idénticos.

Online ↔ Offline

Solo aparece banner amarillo "Modo offline" + dot azul en items pendientes. Layout intacto.

11. Sistema de tokens (resumen)

/* === Spacing scale (8pt base) === */
:root {
  --space-1:  4px;    /* icon-text gap */
  --space-2:  8px;    /* chip padding */
  --space-3:  12px;   /* input vertical padding */
  --space-4:  16px;   /* DEFAULT · card padding */
  --space-5:  24px;   /* card destacada */
  --space-6:  32px;   /* section divider */
  --space-7:  48px;   /* major section break */
  --space-8:  64px;

  /* === Touch targets === */
  --touch-min:      48px;  /* WCAG minimum */
  --touch-default:  56px;  /* Milkbook default */
  --touch-primary:  60px;  /* CTAs principales */
  --touch-huge:     72px;  /* onboarding */

  /* === App structure (mobile) === */
  --statusbar-h:    24px;
  --appbar-h:       56px;
  --bottomnav-h:    56px;
  --sticky-cta-h:   60px;

  /* === Web structure === */
  --sidebar-w:            240px;
  --sidebar-w-collapsed:  72px;
  --web-header-h:         64px;
  --web-density-row:      40px;  /* tablas compact */

  /* === Container max === */
  --container-web: 1280px;
}
