## 🔄 Cómo trabajamos las secciones

1. **Tú indicas qué sección sigue** (por ejemplo: "ahora hagamos iconografía").
2. **Yo investigo opciones** alineadas con lo que ya hay definido (paleta cálida cremosa, tipografía Atkinson/Inter/Lexend/Fraunces, contexto rural de baja alfabetización).
3. **Te traigo opciones comparadas** en un HTML visual + análisis escrito.
4. **Tú decides** qué estilo se ajusta a Milkbook.
5. **Creamos la carpeta** con su `README.md` y mockups.
6. **Pasamos a la siguiente sección.**
