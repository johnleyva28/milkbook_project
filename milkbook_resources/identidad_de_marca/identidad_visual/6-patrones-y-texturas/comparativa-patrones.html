🟫 Milkbook — Patrones y Texturas

Los patrones y texturas son el "toque final" que da calidez y coherencia a la marca. Esta guía define 4 candidatos finales (3 patrones + 1 textura principal + 1 textura kraft opcional), con la paleta Milkbook exacta, y las reglas de cuándo usar cada uno.

1. Los 4 candidatos: 3 patrones + 1 textura + 1 textura kraft (opcional)

Cada uno está renderizado con SVG inline usando la paleta Milkbook. Los marcados con ⭐ son los recomendados para Milkbook.

⭐ RECOMENDADO · ORGÁNICO
1. Gotas de leche azules
Patrón orgánico de gotas en azul (color del logo). Evoca el producto (leche) directamente. Coherente con la paleta cálida cremosa como fondo.
Inspirado en: getillustrations, Hero Patterns (variantes orgánicas), Morphos
⭐ RECOMENDADO · ORGÁNICO
2. Hojas de pasto (realistas)
Patrón orgánico con hojas detalladas (forma de lágrima, nervadura central, ramificación lateral) y briznas de pasto. Evoca el pasto andino de Cajamarca con realismo botánico.
Inspirado en: Outgrow (India), agricultura contextual, AgriTrust, ilustraciones botánicas
3. Puntos crema
Patrón geométrico sutil de puntos. Más "limpio" que los orgánicos. Útil para web admin donde se quiere orden visual.
Inspirado en: Hero Patterns, polka dot vintage, subtle dot patterns
⭐ RECOMENDADO · TEXTURA
5. Textura papel crema (noise)
Textura muy sutil de ruido tipo "papel". Da calidez sin distraer. Coherente con la paleta Milkbook (no rompe el cream-50). Perfecta para fondos.
Inspirado en: Transparent Textures (cream paper), handmade paper, ekru
4. Madera kraft
Textura que evoca madera cálida. Útil para secciones del web admin tipo "artesanal" o boletas PDF. No apto para app móvil (distrae al sol).
Inspirado en: Madera reciclada, craft food packaging, café de especialidad

3. Dónde se aplica cada uno

Patrón / Textura Tipo Casos de uso NO usar en
1. Gotas de leche azules (orgánico) ⭐ Patrón decorativo Hero del web admin, emails, marketing secundario, tarjetas de cliente Fondo de pantalla del app móvil (distrae al sol)
2. Hojas de pasto realistas (orgánico) ⭐ Patrón decorativo Onboarding, splash secundario, marketing, hero web admin Inputs o cards (dificulta lectura)
3. Puntos crema (geométrico) Patrón sutil Web admin, tablas densas, headers App móvil (se siente "tech")
4. Papel crema (noise) ⭐ Textura sutil Boletas PDF, fondo de emails, fondo de marketing App móvil (no se ve en pantallas chicas)
5. Madera kraft (textura) Textura Sección "artesanal" del web admin, packaging físico App móvil, boletas PDF (distrae)

4. Reglas técnicas

Reglas duras para cualquier patrón o textura de Milkbook:
  • ✅ Opacidad 30-60% sobre fondos — los patrones nunca deben competir con el texto
  • ✅ Solo 1-2 colores de la paleta — máximo 2 hex por patrón
  • ✅ SVG repetible (usar <pattern>) o PNG seamless tileable
  • ✅ Coherencia con la marca — verde/crema/azul de la paleta, nunca negro o rojo saturado
  • ❌ NO usar patrones con gradientes — rompe el flat design
  • ❌ NO usar patrones de alto contraste en app móvil (distrae al sol)
  • ❌ NO mezclar más de 2 patrones en la misma pantalla

5. Cómo se usan en código

// CSS — Patrón como background-image
.hero {
  background-image: url('/patterns/gotas-leche.svg');
  background-repeat: repeat;
  background-size: 80px 80px;
  opacity: 0.5;
}

// CSS — Textura noise sobre boleta PDF
.boleta-bg {
  background-color: #FAF8F3;
  background-image: url('/patterns/papel-crema.svg');
  background-blend-mode: multiply;
}

// SVG inline — Patrón dentro del HTML (mejor performance)
<svg width="0" height="0">
  <defs>
    <pattern id="gota" width="80" height="80" patternUnits="userSpaceOnUse">
      <path d="M40 20 Q32 32 32 40 ..." fill="#88D088" />
    </pattern>
  </defs>
</svg>
