✍️ Milkbook — Sistema Tipográfico

Comparativa de fuentes candidatas con texto real de la app, mockups en light/dark, y snippets de instalación para React (web admin), Flutter (cliente + lechero) y Swift (iOS nativo).

1. Por qué NO una sola fuente

Una sola familia no puede ser excelente en todo. Milkbook necesita:

  • Para datos numéricos (litros, montos): fuente que distinga 0/O, 1/l/I y S/5/$ sin confundirlos. Crítico cuando lees el monto total.
  • Para UI densa (botones, labels, navegación): fuente con x-height alta que aproveche el espacio y se lea bien al sol.
  • Para el wordmark y marketing: fuente con personalidad que diferencie a Milkbook de apps genéricas.
Recomendación final: 4 familias, 4 roles. Atkinson Hyperlegible Next (datos en app) + Inter (UI general) + Lexend (lectura larga en web admin) + Fraunces (display/wordmark). Todas gratuitas, OFL, disponibles en Google Fonts.

1b. Disponibilidad, costo y soporte multiplataforma

Las 4 fuentes elegidas son 100% gratuitas bajo la licencia SIL Open Font License (OFL) — uso comercial libre, redistribución libre, modificación libre, sin atribución obligatoria. No hay letra chica, no hay costo oculto.

¿Cómo verifico la licencia? Cada archivo TTF/OTF incluye un archivo LICENSE.txt o OFL.txt adjunto. OFL permite: uso comercial, redistribución, modificación. Solo prohíbe vender la fuente por sí sola.

5. Snippets de instalación

🌐 React / Next.js — Web Admin

// app/layout.tsx — Next.js 13+ con next/font (self-hosted, sin FOUT)
  import { Atkinson_Hyperlegible_Next, Inter, Lexend, Fraunces } from 'next/font/google'

  const atkinson = Atkinson_Hyperlegible_Next({
    subsets: ['latin', 'latin-ext'],   // incluye ñ, tildes
    weight: ['400', '500', '600', '700'],
    variable: '--font-data',
    display: 'swap',
    preload: true,
  })

  const inter = Inter({
    subsets: ['latin', 'latin-ext'],
    variable: '--font-ui',
    display: 'swap',
  })

  const lexend = Lexend({
    subsets: ['latin', 'latin-ext'],
    weight: ['300', '400', '500', '600', '700'],
    variable: '--font-reading',
    display: 'swap',
  })

  const fraunces = Fraunces({
    subsets: ['latin'],
    weight: ['500', '700'],
    variable: '--font-display',
    display: 'swap',
  })

  export default function RootLayout({ children }) {
    return (
      <html lang="es" className={`${atkinson.variable} ${inter.variable} ${lexend.variable} ${fraunces.variable}`}>
        <body>{children}</body>
      </html>
    )
  }

// Extensión para usar Atkinson Hyperlegible en datos
extension DataText on TextStyle {
  TextStyle data({double? size, FontWeight? weight, Color? color}) => copyWith(
    fontFamily: MilkbookTheme.fontData,
    fontSize: size ?? fontSize,
    fontWeight: weight ?? fontWeight,
    color: color,
    height: 1.2,
    leadingDistribution: TextLeadingDistribution.even,  // fija leading cross-platform
  );
}

// Extensión para usar Lexend en lectura larga (web admin)
extension ReadingText on TextStyle {
  TextStyle reading({double? size, FontWeight? weight}) => copyWith(
    fontFamily: MilkbookTheme.fontReading,
    fontSize: size ?? fontSize,
    fontWeight: weight ?? FontWeight.w400,
    height: 1.7,
  );
}

// ⚠️ El nombre que se pasa a Font.custom() es el PostScript Name del .ttf,
// no el nombre del archivo. Verificarlo abriendo el .ttf en Font Book (macOS)
// o imprimiendo UIFont.familyNames en el log al arrancar.
// Lexend SOLO se embebe si la app iOS también incluye módulo de reportes
// (versión admin móvil). Si es solo la app del lechero/cliente, omitir Lexend.
// FontManager.swift — registrar con fallback seguro
import SwiftUI
import CoreText

enum MilkbookFont: String {
    case dataRegular    = "AtkinsonHyperlegibleNext-Regular"
    case dataBold       = "AtkinsonHyperlegibleNext-Bold"
    case uiRegular      = "Inter-Regular"
    case uiMedium       = "Inter-Medium"
    case uiSemibold     = "Inter-SemiBold"
    case uiBold         = "Inter-Bold"
    case readingLight   = "Lexend-Light"
    case readingRegular = "Lexend-Regular"
    case readingMedium  = "Lexend-Medium"
    case displayMedium  = "Fraunces-Medium"
}

extension Font {
    /// Tipografía semántica: dato numérico (litros, montos)
    static func milkbookData(_ size: CGFloat, weight: Font.Weight = .regular) -> Font {
        let name = (weight == .bold) ? MilkbookFont.dataBold.rawValue : MilkbookFont.dataRegular.rawValue
        return Font.custom(name, size: size, relativeTo: .title)
    }

    /// Tipografía semántica: UI general
    static func milkbookUI(_ size: CGFloat, weight: Font.Weight = .regular) -> Font {
        let name: String
        switch weight {
        case .bold:     name = MilkbookFont.uiBold.rawValue
        case .semibold: name = MilkbookFont.uiSemibold.rawValue
        case .medium:   name = MilkbookFont.uiMedium.rawValue
        default:       name = MilkbookFont.uiRegular.rawValue
        }
        return Font.custom(name, size: size, relativeTo: .body)
    }

    /// Tipografía semántica: lectura larga (reportes, liquidaciones)
    static func milkbookReading(_ size: CGFloat, weight: Font.Weight = .regular) -> Font {
        let name: String
        switch weight {
        case .light:   name = MilkbookFont.readingLight.rawValue
        case .medium:  name = MilkbookFont.readingMedium.rawValue
        default:      name = MilkbookFont.readingRegular.rawValue
        }
        return Font.custom(name, size: size, relativeTo: .body)
    }

    /// Wordmark (solo branding)
    static var milkbookWordmark: Font {
        Font.custom(MilkbookFont.displayMedium.rawValue, size: 32, relativeTo: .largeTitle)
    }
}
