4. Sistema tipográfico

Tres roles, tres familias. Cada una con una razón específica para Milkbook.

📊 Familia DATA — Atkinson Hyperlegible

18.5 L · S/ 12.03 · Juan Mamani Uso: números, montos, litros, nombres propios, datos del cliente

Por qué: diseñada por el Braille Institute específicamente para baja visión y baja alfabetización. Cada glifo es único y no se confunde con otro (la "I", la "l" y el "1" son distintos). Gratis, OFL, soporta 150+ idiomas. Recomendación #1 para Milkbook.

🖥️ Familia UI — Inter

Confirmar litros del día Uso: títulos, botones, labels, navegación, textos secundarios

Por qué: estándar moderno de UI. x-height alta (texto se ve más grande al mismo tamaño), máxima legibilidad, variable font, distingue bien caracteres similares. Usada por GitHub, Figma, Linear. Web admin de Milkbook.

📜 Familia DISPLAY — Fraunces

Milkbook Uso: solo el wordmark del logo, onboarding, splash screen, marketing

Por qué: serif humanista con personalidad. Aporta calidez y diferenciación sin sacrificar legibilidad. Reservar para ocasiones especiales — no usar en UI diaria para evitar inconsistencias.

✅ Sistema completo

Colores light + dark derivados del logo · WCAG AA/AAA verificado en pares críticos.
Tres familias tipográficas con roles claros: Atkinson Hyperlegible para datos, Inter para UI, Fraunces para el wordmark.
