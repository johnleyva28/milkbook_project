# MilkBook App

Aplicación móvil nativa de **MilkBook**, orientada a la gestión y comercialización de leche y productos lácteos.

## Plataforma

- **iOS:** Swift / SwiftUI
- **Backend:** NestJS
- **Frontend web:** React + TypeScript + Vite

## Descripción

MilkBook busca facilitar la gestión de la compra y venta de leche, conectando a compradores y productores mediante una aplicación móvil nativa para iOS.

La aplicación permitirá consultar productos, gestionar operaciones relacionadas con la compra y venta de leche y acceder a los servicios proporcionados por el backend de MilkBook.

## Estado

🚧 En desarrollo.

La aplicación iOS será inicializada y desarrollada nativamente con **Swift y SwiftUI** desde macOS utilizando Xcode.
