# Idea B — Competidores (Dairy Tech)

## Panorama del mercado

El mercado de software para la cadena láctea tiene tres capas:

1. **Software para productores grandes / establos** (con robots de ordeño).
2. **Software para la industria transformadora / centros de acopio formales** (ruta calidad, trazabilidad).
3. **Software para pequeños productores / intermediarios** (registros básicos, WhatsApp-first).

## Capa 1: Software para productores grandes / establos

### Pastura (España)
- **URL:** pastura.es
- **Modelo:** SaaS por plan según número de animales.
- **Diferenciador:** Conexión con robots de ordeño (Lely T4C, estándar ICAR), libro de explotación digital, facturación VeriFactu (normativa española 2027).
- **Funciona offline** (importante para establos sin cobertura).
- **Idioma:** Español.
- **Fortalezas:** Profundidad técnica, integración con robots, cumplimiento normativo español.
- **Debilidades:** Diseñado para España; no conoce normativa peruana.

### AlphaMilk
- **URL:** alphamilk.es
- **Modelo:** SaaS con tres planes.
- **Diferenciador:** Chatbot IA integrado, KPIs personalizables, multi-plataforma.
- **Idioma:** Español.

### asmLácteo (ASM Soft, España)
- **URL:** asm.es/erp-bi/asmlacteo/
- **Modelo:** ERP vertical para industria láctea española.
- **Diferenciador:** Cumplimiento de la **normativa "Letra Q"** (España); integración con laboratorio; gestión de cuotas INLAC; tarifas por calidad, primas, penalizaciones.
- **Idioma:** Español.
- **Fortalezas:** Muy específico para el sector lácteo; cumplimiento normativo robusto.
- **Debilidades:** Para industria formal, no para pequeños productores.

### GanaderiAPP
- **URL:** ganaderiapp.tech
- **Modelo:** Freemium (G One gratis hasta 150 animales); planes G Pro ($20), G Apex ($130).
- **Mercado:** Latinoamérica.
- **Diferenciador:** Multi-hacienda, multi-moneda, app nativa + web.
- **Idioma:** Español.
- **Fortalezas:** LatAm-focused, escalable.

### Progan Software Ganadero
- **URL:** progansoftware.com
- **Modelo:** Pago anual; edición gratuita limitada.
- **Diferenciador:** **Funciona sin Internet** (clave para zonas rurales); multifinca; planes Pro con importación desde Excel.
- **Idioma:** Español.
- **Fortalezas:** Offline-first, sin requerir conexión constante.

### Bovi Control / Uniform-Agri / GanaderosOnline
- Modelos europeos para gestión interna de establos.
- Profundidad técnica, pero requieren ordenador y formación.

### MeriDairy (India)
- **URL:** mwm.ai/es/apps/meri-dairy-milk-app
- **Modelo:** App standalone.
- **Diferenciador:** **SMS-based entries** para áreas con conectividad irregular. Pensado específicamente para "áreas rurales con conectividad irregular".
- **Idioma:** Inglés / hindi.
- **Fortalezas:** SMS-first → cero dependencia de internet.
- **Debilidades:** Diseñado para India, no Perú.

### DJS Dairy
- **URL:** dairy-milk-manager (Aptoide)
- **Modelo:** App Android standalone.
- **Diferenciador:** Modo offline robusto, múltiples clientes, generación de facturas PDF, soporte para impresoras térmicas Bluetooth, biometría.
- **Idioma:** Español.
- **Fortalezas:** Offline, facturación.
- **Debilidades:** UI básica, no SaaS, no multi-tenant.

## Capa 2: Software para industria / acopio formal

### Tribu Hacienda (Ecuador)
- **URL:** tribufy.cloud/tribu-hacienda
- **Modelo:** SaaS vertical agro-ganadero. **$45-85/mes**.
- **Diferenciador:** **Cumplimiento NIIF + SRI (Ecuador) + NIC 41 (activos biológicos)** integrado. App móvil para vaqueros. **Modo offline**.
- **Idioma:** Español.
- **Fortalezas:** Cumplimiento normativo ecuatoriano integrado. Multi-finca. Modo offline. Costos $/Litro reales.
- **Debilidades:** Solo Ecuador. Cumplimiento tributario ecuatoriano, no peruano.
- **ENSEÑANZA PARA NOSOTROS:** Es exactamente el producto que necesitamos para Perú, pero con SUNAT/Perú.

### Software para SENASA / Gobiernos Regionales (Perú)
- **GANASAM (San Martín):** Aplicativo del Gobierno Regional de San Martín para la Granja Ganadera de Calzada. Control de inventario, sanitario, reproductivo. App móvil + web.
- **Agrodigital (MIDAGRI):** App oficial para productores registrados en el Padrón de Productores Agrarios (PPA).
- **SENASA:** Programa de identificación con aretes DIO.

> **[HECHO]** Existe infraestructura pública previa que demuestra que **el Estado peruano reconoce la necesidad de digitalizar la cadena**.

## Capa 3: Software para pequeños productores / WhatsApp-first

### Surco (Argentina)
- **URL:** surco.lat
- **Modelo:** Gratis (1 campo), Pro USD 19/mes, A Medida.
- **Diferenciador:** **WhatsApp-first**. El productor manda audios o fotos; la IA interpreta y registra.
- **Idioma:** Español.
- **Fortalezas:** **Cero fricción de adopción** – no se instala otra app.

### Harvis (LatAm)
- **URL:** harvis.app
- **Modelo:** B2C gratis (10 consultas/semana) + B2B.
- **Diferenciador:** WhatsApp-first, IA, asistencia técnica.

### GanaderoAI (Panamá, Costa Rica, Guatemala)
- **URL:** ganaderoai.com
- **Modelo:** B2B SaaS.
- **Diferenciador:** WhatsApp-first, OCR de facturas con RUC, multi-finca, soporte multi-país.
- **Idioma:** Español.

### FieldData Agro (Argentina)
- **Mercado:** Argentina, Uruguay, Paraguay, Chile, Brasil, México, Colombia.
- **Adopción:** 3,000+ establecimientos, 1.5M+ hectáreas.
- **Diferenciador:** WhatsApp-first, informes semanales PDF con imagen satelital NDVI.
- **Idioma:** Español.

## Software público peruano (referencia)

## Hallazgo crítico

> **No existe un producto SaaS multi-tenant que:**
> 1. Esté diseñado específicamente para pequeños productores lácteos en Perú.
> 2. Integre **WhatsApp** como canal primario.
> 3. Integre **SUNAT / facturación electrónica**.
> 4. Funcione **offline** en zonas rurales.
> 5. Tenga **trazabilidad de precio** como feature central.

**Ese es exactamente el espacio donde nuestro producto podría competir.**

## Comparación con el modelo "Surco-like"

Surco es el **mejor modelo conceptual** para el productor peruano:
- WhatsApp-first.
- Sin app que instalar.
- Audio o foto se convierte en registro.
- Gratis para empezar.

**Diferenciador que necesitamos:** Ser **específico para leche** (no agro genérico) e **integrar el flujo comercial** (precio, liquidación, factura), no solo la operación de campo.

## Implicaciones para nuestro proyecto

1. **El modelo Surco (WhatsApp-first) es la referencia**, pero aplicado a leche.
2. **Integración con SUNAT** es **crítica** y diferenciadora (Tribu Hacienda lo hizo con SRI).
3. **Modo offline** es esencial para el MVP.
4. **Multi-tenant** desde día 1 para que cada comprador/acopio sea un tenant.
5. **No，我们要 competir** con Tribu Hacienda (Ecuador), sino **replicar su modelo para Perú**.
