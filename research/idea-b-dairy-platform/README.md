# Idea B — Plataforma de gestión de compra/venta de leche

## Resumen ejecutivo

Esta carpeta documenta la idea de construir una plataforma digital para la cadena láctea, inicialmente pensada para el caso familiar del usuario (su madre vende leche a un comprador cada 15 días), pero investigando toda la cadena láctea peruana: productores, intermediarios, centros de acopio, transformadores.

> **Conclusión preliminar:** El problema es **real, doloroso y sub-atendido por software especializado en Perú**. Hay decenas de soluciones internacionales (asmLácteo, Pastura, AlphaMilk, GanaderiAPP, MeriDairy, Tribu Hacienda) pero **ninguna construida para el caso del pequeño productor de la sierra peruana**. El mercado informal en Cajamarca es enorme (60,000 L/día solo en Celendín, 90,000 familias en Cajamarca).
