# Investigación de Producto Integrador

Este directorio contiene una investigación profesional de producto y descubrimiento de software para definir el **proyecto integrador** del 5to ciclo 2026-II.

## Objetivo

Decidir, con evidencia, cuál de las dos ideas propuestas debería convertirse en el proyecto integrador:

- **Idea A**: Plataforma para Asambleas de Dios del Perú (LADP), pensada inicialmente para la Región Eclesiástica de Celendín.
- **Idea B**: Sistema de gestión de compra/venta de leche para pequeños productores rurales y compradores/intermediarios.

El proyecto integrador debe permitir integrar Node.js + Express, React + Vite + TypeScript, Flutter (iOS/Android), Docker, PostgreSQL, API REST, autenticación, migraciones y arquitectura backend moderna.

## Metodología

La investigación se organiza en 7 fases:

1. **Exploración** – barrido amplio de ambas ideas.
2. **Profundización** – nuevas búsquedas sobre hallazgos clave.
3. **Validación** – contraste entre múltiples fuentes.
4. **Análisis** – patrones, problemas, oportunidades, riesgos.
5. **Comparación** – tabla comparativa Idea A vs Idea B.
6. **Recomendación** – argumentación de la mejor dirección.
7. **Definición del producto** – MVP, roles, procesos, modelo de datos, arquitectura.

## Principios rectores

- **Evidencia primero, conclusión después.**
- Distinguir siempre entre **hechos comprobados**, **inferencias**, **hipótesis** y **suposiciones que requieren validación**.
- Pensamiento crítico activo: buscar contraevidencia.
- Citar fuentes verificables. No inventar URLs ni datos.
- Si una fuente no es accesible, declararlo.
